# Hart Werkplek

Schermvullend werkprogramma voor Windows met ingebouwde browsers (Outlook, James, reMarkable, caseload) en eigen hulpmiddelen: startpagina met to do's en bellijst, klembord, sessieverslag, interventiecatalogus en sessieblad bouwer.

## Eerste keer installeren

1. Klik hierboven op de groene knop **Code** en kies **Download ZIP**.
2. Pak de zip uit en dubbelklik op **Installeer Hart Werkplek.bat**.
   Geeft Windows een blauwe waarschuwing? Klik op *Meer informatie* en dan *Toch uitvoeren*.
3. Start Hart Werkplek via de snelkoppeling op je bureaublad.

Er zijn geen beheerdersrechten nodig: het programma komt alleen in je eigen gebruikersaccount te staan.

## Bijwerken

Klik in het programma links onderin op **Bijwerken**. Staat er *(nieuw)* achter, dan is er een nieuwere versie. Het programma haalt die hier op, installeert hem en start opnieuw op. Instellingen, inlogs en to do's blijven bewaard.

## Privacy

In deze repository staan alleen het programma en algemene teksten. Instellingen (zoals het adres van James), to do's, inlogs en het klembord staan alleen op de eigen computer.
